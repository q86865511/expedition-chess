## 6. 垂直切片內容預算

### 6.1 內容數量

| 內容 | 數量 | 必要分布／條件 |
|---|---:|---|
| 玩家棋子 | 32 | 1–5 費為 10／8／6／5／3 |
| 陣營羈絆 | 6 | 每條至少有一個可達門檻 |
| 職能羈絆 | 6 | 每條至少有一個可達門檻 |
| 三標籤棋子 | 4 | 需有明確稀有度或規則代價 |
| 裝備零件 | 6 | 所有無序配對均合法 |
| 完整裝備 | 21 | 每個配方唯一 |
| 遺物 | 至少 15 | 戰鬥／經濟／路線／規則型皆有 |
| 指揮官 | 3 | 不上場、規則型、不同起始選擇 |
| 專屬怪物 | 12 | 可跨遭遇重組 |
| 菁英詞綴 | 6 | 不直接複製遭遇 |
| Boss | 3 | 每幕一個，至少一個階段機制 |
| 短事件 | 至少 12 | 每個至少兩個有代價的選項 |
| 節點類型 | 7 | 普通、菁英、商人、事件、休整、寶藏、Boss |
| 挑戰階級 | 5＋基礎 | 逐階解鎖、詞綴累積 |

- **[REQ-CONTENT-001]** 內容驗證器必須精確驗證上述最低數量與分布，缺少任何 MUST 內容時匯出失敗。

### 6.2 玩家棋子費用分布

| 費用 | 數量 | 主要設計責任 |
|---:|---:|---|
| 1 | 10 | 前期成形、基礎前後排、羈絆入口 |
| 2 | 8 | 轉陣橋接、功能型技能 |
| 3 | 6 | 中期核心、構築方向確認 |
| 4 | 5 | 後期核心、強力但需投入 |
| 5 | 3 | 稀有規則型單位；不得單卡無條件取代整套構築 |

32 隻棋子不要求本文件集命名，但後續 roster spec 必須提供一張 32×標籤矩陣，驗證每條羈絆的門檻與替代路徑。

### 6.3 完整角色美術契約

每隻玩家棋子至少具有：

- 獨立剪影、配色與可辨識武器／職能語彙。
- 商店／圖鑑頭像、羈絆圖示引用與棋盤小圖示。
- 待機、八方向或視覺可等價映射的移動、普攻、施法、受擊、死亡動畫。
- 一星基礎外觀；二星、三星至少有清楚但不改碰撞／格位的視覺強化。
- 技能預警、命中、傷害類型與狀態效果的可讀回饋。
- 色弱模式下不只靠色相區分的羈絆與陣營標記。

專屬怪物與 Boss 使用同樣的可讀性要求；可共用動畫語法，但不得以單純換色取代所有差異。

## 7. 局外營地與水平成長

### 7.1 營地設施

| 設施 | 功能 | 可變狀態 |
|---|---|---|
| 遠征門／戰略桌 | 選擇指揮官、挑戰階級並開始遠征 | 最近選擇、最高挑戰 |
| 指揮官廳 | 檢視與解鎖指揮官 | 已解鎖 ID |
| 圖鑑館 | 檢視棋子、羈絆、裝備、遺物、怪物 | 發現／解鎖狀態 |
| 解鎖工坊 | 使用單一局外貨幣取得可選內容 | 貨幣、購買紀錄 |
| 挑戰碑 | 檢視挑戰詞綴與通關紀錄 | 各指揮官最高通關 |

營地允許玩家自由移動，但不包含建造、產能、NPC 日程或資源等待。

### 7.2 指揮官

- 指揮官不上棋盤、不佔人口、不可裝備，也不提供戰中主動操作。
- 每名指揮官包含一個起始棋子或起始資源包、一個規則型被動及一個路線／獎勵偏好。
- 三名指揮官的優勢不得只是相同被動的數值階級。
- 指揮官選擇在建立 `RunState` 時鎖定，遠征中不得更換。

### 7.3 解鎖

- 使用一種局外貨幣，暫稱 `meta.currency`；正式名稱由世界觀文件決定，不影響 stable ID。
- 關鍵系統透過里程碑解鎖；可選內容使用貨幣購買。
- 可解鎖內容包括指揮官、新棋子池、新遺物、新事件、起始包與挑戰詞綴。
- 解鎖棋子或物品後，只影響未開始的新遠征；進行中的 `RunState` 保留建立時的 `content_snapshot`。
- 不允許永久增加玩家基礎生命、棋子基礎攻防、商店免費刷新或固定起始人口。

局外貨幣由版本化 `MetaRewardTableDef` 在遠征結算時計算。垂直切片初值：

- 每個成功通過的普通戰：1。
- 每個成功通過的菁英戰：3。
- 每個成功擊敗的 Boss：5。
- 通關第三幕額外：10。
- Challenge 1–5 最後乘以 `100% + 10% × challenge_level`，向下取整。
- 戰敗本身不給節點分數，但保留該局先前成功通過的戰鬥。

結算使用 `run_id` 建立不可重複的 `settlement_receipt`。Profile 貨幣、里程碑、挑戰紀錄、receipt 與 active run 清除必須在同一原子存檔交易中提交；重載 RESULTS 不得重複發放。

### 7.4 挑戰階級

- 基礎難度為 Challenge 0。
- Challenge 1–5 逐階解鎖，需先通過前一階。
- 詞綴可調整敵人編成、遭遇規則、經濟壓力或遠征傷害，但必須在遠征開始前完整列出。
- 挑戰進度按指揮官記錄，整體最高階也存於 profile。

- **[REQ-META-001]** 營地必須提供遠征、指揮官、圖鑑、解鎖與挑戰五類功能入口。
- **[REQ-META-002]** 局外成長只能擴充選項或難度，不得永久提高玩家或棋子的基礎戰力。
- **[REQ-META-003]** 進行中遠征的內容快照不得因局外解鎖或資料熱重載改變。
- **[REQ-META-004]** 每場遠征的局外貨幣與進度結算必須由 MetaRewardTableDef 計算，並以 run_id receipt 保證 exactly once。
