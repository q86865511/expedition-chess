## 10. 像素呈現、UI 與無障礙

### 10.1 渲染策略

- 邏輯世界以 640×360 的 `SubViewport` 渲染，使用 nearest-neighbor 與整數縮放。
- UI 使用獨立 `CanvasLayer`，最低設計解析度為 1280×720；在 1920×1080、2560×1440 等解析度維持可讀文字，不把 CJK 字型強制縮成世界像素格。
- 目標比例為 16:9；其他比例以 letterbox／安全區處理，不拉伸世界像素。
- 棋盤邏輯仍是方格；3/4 視覺投影只負責格位到畫面座標轉換，不進入 domain 模擬。
- 相機不得使用造成半像素取樣的縮放或平移；世界 sprite 停在整數像素。
- 畫面特效可以超出格位，但不得遮蔽敵方技能預警、血條或選取狀態。

- **[REQ-UX-001]** 世界與 UI 必須分離渲染，使像素資產保持銳利，同時讓繁體中文在 720p 以上維持可讀。

### 10.2 主要畫面

| 畫面 | 必要資訊 | 主要操作 |
|---|---|---|
| 主選單 | 繼續、開始、設定、離開 | 滑鼠、鍵盤 |
| 營地 | 設施方向、互動提示、貨幣 | 移動、互動 |
| 遠征地圖 | 路徑、節點類型、可達性、幕進度 | 選節點、查看預覽 |
| 備戰 | 棋盤、板凳、商店、金幣、XP、羈絆、物品、敵情 | 購買、刷新、佈陣、鍛造 |
| 戰鬥 | 雙方狀態、技能預警、倍速、暫停、事件摘要 | 檢視、暫停、倍速 |
| 獎勵 | 候選的完整效果、容量衝突 | 三選一、替換、放棄 |
| 結算 | 路線、構築、解鎖、貨幣、挑戰進度 | 確認返回 |
| 圖鑑 | 發現／解鎖內容、配方、規則詞彙 | 篩選、搜尋、比較 |

### 10.3 備戰互動

- 拖曳棋子時顯示合法格、交換預覽、人口使用與羈絆變化。
- 商店卡顯示費用、標籤、技能摘要、目前持有副本與購買後是否升星。
- 刷新、購買 XP、出售、鍛造、拆卸與放棄獎勵均有清楚成本及結果預覽。
- 不可逆操作（鍛造、替換遺物、事件選擇、放棄獎勵）需要一次確認；一般購買與佈陣不需多餘確認。
- 預覽數值直接來自內容定義與同一公式服務，不得在 tooltip 複製公式。

### 10.4 戰鬥控制

- 支援暫停、1×、2×、4×。
- 暫停與倍速只改變 presentation 消費事件的速度及模擬排程，不改變事件順序或戰果。
- 戰中可點選單位檢視來源、目標、stats、裝備、羈絆與狀態。
- 戰中不得購買、換裝、移動棋子、施放技能或指定目標。

- **[REQ-UX-002]** 戰鬥暫停與倍速不得改變 canonical 戰鬥摘要。

### 10.5 無障礙

- 羈絆、稀有度、傷害類型與敵我關係不得只靠顏色表達，需同時使用圖示、形狀或文字。
- 提供三種常見色覺模式的調色盤替換。
- 提供 UI 縮放至少 100%、125%、150%。
- 支援關閉螢幕震動、降低閃爍、降低粒子及調整傷害數字密度。
- 所有滑鼠主要操作提供鍵盤焦點路徑；垂直切片不要求完整控制器支援。
- 繁體中文使用可讀 CJK 字型；像素字型只用於短標題，不用於長說明。
- Tooltip 支援規則詞彙巢狀展開，但最多兩層，避免無限彈窗。
- 所有玩家可見文字必須使用 localization key，不得在場景或 domain 硬編碼繁中文字串；`zh_TW` 在 G2 必須完整，並維護相同 key 集合的英文目錄以預留 `en`。必要 key 缺失時內容驗證失敗，開發 build 顯示 key 本身供診斷。

- **[REQ-UX-003]** 所有影響決策的資訊必須可由非色彩訊號辨識，且 UI 縮放後不得截斷必要操作。
- **[REQ-UX-005]** 所有玩家可見文字必須由 localization key 提供，G2 的繁中目錄完整且英文目錄具有同一 key 集合。

### 10.6 效能基線

參考最低 PC：

- Windows 10／11 64-bit。
- 4 核心 2.5 GHz CPU。
- 8 GB RAM。
- Intel UHD 630 或相當等級整合顯示。
- 1280×720。

目標：

- 正常 12 對 12 戰鬥維持 60 FPS。
- 壓力情境每方 16 個部署單位、總計 64 個含召喚物實體時，畫面維持至少 55 FPS，模擬不得漏 tick。
- headless 模擬單 tick 的 p99 在參考 PC 不超過 8 ms。
- 戰鬥事件佇列不得無界成長；presentation 落後時合併純視覺事件，不丟棄規則事件。

若內容驗證器算出的版本最大可達人口高於 16，壓力情境的每方部署數提高至該最大值；同時實體下限提高至 `max(64, 雙方最大部署數 + 所有合法召喚上限)`，不得仍以 16／64 宣稱通過。

- **[REQ-UX-004]** 垂直切片必須在參考最低 PC 通過正常與壓力效能基線。
